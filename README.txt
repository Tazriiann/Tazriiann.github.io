HOW TO UPLOAD (any static host — Netlify, Vercel, GitHub Pages,
Hostinger, cPanel hosting, etc.)
----------------------------------------------------------------
Option A — drag & drop hosts (Netlify Drop, Vercel):
  Unzip this file, then drag the unzipped FOLDER onto the host's
  upload area. Done — index.html is your homepage.

Option B — cPanel / traditional hosting:
  1. Open File Manager and go into "public_html".
  2. Upload this ZIP file there, right-click it and choose Extract.
  3. Delete the ZIP from public_html afterwards.
  Your site is live at your domain.

Option C — GitHub Pages:
  Create a repository, upload all files and folders from inside
  this ZIP (keeping the structure), then enable Pages in Settings.
